# Yanko

ITスクール「RareTECH」でWeb開発を学びながら、
個人開発やチーム開発を通じて、設計・実装の経験を積んでいます。

現職では、業務システムを使う側として改善に関わってきました。<br>
クリックやスクロールなど、一つひとつは小さな操作でも、日々積み重なると大きな業務負担になります。<br>
使う人の動きや業務の流れに想像力を働かせながら、<br>
小さな快適を積み上げる設計・実装を大切にしています。

## Projects

### ポッケ
子どもの「もらう・つかう」をその場で記録し、お金のやり取りを親子で手軽に楽しむバーチャルお財布アプリ。

React / TypeScript / Vite

### Teamy
価値観の違いを可視化し、チーム内のコミュニケーション改善を支援するアプリ。
UI設計とフロントエンド実装を中心に担当しました。

Django / Tailwind CSS / MySQL

### Tabitalk
47都道府県別のチャットルームで、旅行情報やおすすめスポットを共有できる
旅行コミュニティアプリ。

サインアップ・ログイン・ホーム画面などのUI設計・実装を担当しました。

Flask / MySQL / JavaScript / Docker

### ゴハンドースル
毎日の献立決めをラクにするための、家族で献立相談やルーレット決めなどを行うアプリ。

APIの設計・実装など、バックエンド実装を担当しました。

Flask / MySQL / Docker
